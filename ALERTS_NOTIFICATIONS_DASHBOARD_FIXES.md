# Alerts + Notifications Dashboard Build

Included changes:

- Overview tab now uses operational attendance blocks instead of static system information.
- Alerts for staff not signed in, late arrivals, missing sign-outs, outside-area GPS issues and low accuracy.
- Notifications table is created automatically on backend use.
- Dashboard shows smart suggestions and unread notifications.
- HR Staff now has sub-tabs: View Staff and Add New Employee.
- HR Staff uses one unified form with an Assign to / Role dropdown for Manager and employee roles.
- Existing View/Edit/Delete/Reset Password actions remain available.
- Delete still makes staff inactive and keeps database records.
