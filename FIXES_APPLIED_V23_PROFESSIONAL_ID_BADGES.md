# V23 Professional ID Badge Layout

Updated printable and digital staff ID cards to look like real company badges:

- Larger top-right logo on printable PDF cards.
- Clean badge header with brand area.
- Cropped portrait photo locked inside the photo block.
- QR code placed in its own scan block so it cannot overlap the photo/text.
- Purple footer band with staff ID and validity label.
- Digital ID card restyled to match the printable badge.
- Mobile-safe digital layout sizing.
