# Version 2.1 operational fixes

- Managers included as commission participants and can submit their own claims.
- Franchise users see managers and employees on the commission page.
- Managers see only their linked employees plus their own commission record.
- Commission structures, calculations, submissions, review notifications and reports use one shared staff flow.
- Staff listing endpoints support manager scope.
- Employee updates preserve omitted login, ID and password fields.
- Login includes Show/Hide Password.
- Forgot Password sends a secure one-hour reset link through SMTP.
- Additional office addresses can be created under Business Information.
- Mobile attendance Done returns to the mobile home/menu.
